# Banking Performance Analytics

**Oracle SQL | PL/SQL | Financial Data Analytics**

## Project Overview
This project focuses on banking performance analysis using Oracle SQL and PL/SQL. It covers credit portfolio monitoring, sales performance, non-interest income analysis, and KPI reporting across different banking segments.

## Key Components

**1. SME Performance Analysis**
- Credit portfolio analysis for small and medium enterprises
- Loan disbursement and sales volume reporting
- New vs. returning customer analysis
- Overdraft, credit line, and NPL monitoring

**2. Corporate Performance Analysis**
- Corporate credit portfolio monitoring
- Loan sales and customer segmentation
- Credit line and overdraft analysis
- Financial KPI calculations

**3. Non-Interest Income Analysis**
- Domestic and international payment commissions
- SWIFT transaction income
- Foreign exchange dealing income
- Cash operations and account service fees
- Revenue analysis by customer segment

## Technical Skills
- Oracle SQL and PL/SQL
- Stored Procedures
- Common Table Expressions (CTEs)
- JOIN and GROUP BY operations
- Aggregate Functions
- CASE Expressions
- Data Transformation
- KPI Reporting

## Reporting Logic
The SQL procedures calculate financial indicators using reporting-date parameters and month-end aggregation logic.
